# 👟 Adidas Sales Analysis | Excel Dashboard

## 📌 Project Overview

The **Adidas Sales Analysis** project focuses on analyzing Adidas sales data to understand business performance across different retailers, product categories, geographical regions, and sales methods.

The project uses Excel data analysis and summary reports to explore sales revenue, operating profit, units sold, and regional performance.

## 🎯 Project Objectives

- Analyze overall Adidas sales performance.
- Identify top-performing retailers.
- Compare sales across different product categories.
- Analyze regional sales distribution.
- Evaluate operating profit and profit margins.
- Compare In-store, Online, and Outlet sales methods.
- Understand sales trends over time.
